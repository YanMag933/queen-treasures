# Сокровища королевы

Премиальный финансовый трекер для телефона: светлая казна, доходы и расходы за день, аналитика по плану до августа 2027, долги снежным комом и свадебный фонд.

## Как открыть на телефоне

Постоянная ссылка, как у Iron Coach:

**https://yanmag933.github.io/queen-treasures/**

1. Открой её на телефоне (iPhone — в Safari).
2. «На экран Домой» / «Установить приложение».
3. Если после обновления видна старая версия: https://yanmag933.github.io/queen-treasures/reset.html

Данные хранятся только на устройстве. Репозиторий лучше сделать **приватным**.

## Ежедневные надписи

Мягкий коуч меняет текст каждый день и дополнительно подстраивается под записи: хвалит за факт, аккуратно подсвечивает, если доход отстаёт или лимит расходов скрипит.
